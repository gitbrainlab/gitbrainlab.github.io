# Changelog

## 0.1.0-rc.1 — 2026-10-10

Initial public specification and reference toolkit under `specs/civicspec` in `gitbrainlab/gitbrainlab.github.io`.

- Publish the 23-section adoption and maintenance contract, updated to the user-selected canonical repository.
- Add conceptual model, worked examples, agent onboarding, integration, release, evaluation, contribution, and governance documentation.
- Preserve a selected September research baseline with original bytes and hashes; distinguish historical research results from this repository's executable checks.
- Add a draft synthetic-assertion schema, source-selector checks, negative regression tests, release verification, and CI.
- Publish an experimental candidate inventory at a pinned source commit; keep stable unset.

This publication does not deploy a civic extractor, a custom website, or a live bot fleet. It does not declare full SHACL conformance, independently validated accuracy, or a project license.
